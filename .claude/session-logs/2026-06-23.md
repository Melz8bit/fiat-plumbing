# Session Log — 2026-06-23

## Summary
Built out the company document management system (upload, tracking, version selection for emails), overhauled the License & Insurance Submissions admin page, and added multiple contacts per client.

## Work Done

### Company Documents — New Feature
- Created `company_documents` Supabase table (`id`, `doc_type`, `s3_key`, `folder`, `filename`, `user_id`, `upload_date`, `expiration_date`)

### License & Insurance Submissions Admin Page
- Renamed page from "Certificate of Liability" to "License & Insurance Submissions" (title, heading, nav)

- `send_coi_email()`: now accepts `state_license_key`, `btr_key`, `coi_year` as parameters; builds dynamic email body listing only actually-attached docs; attachment filenames derived from S3 key (includes year)
- Added "Document Versions to Send" card above entity table with three dropdowns:

  - **State License** — filtered from `company_documents` where `doc_type` contains "state license"
  - **BTR** — filtered from `company_documents` where `doc_type` contains "btr" or "business tax"
- Reordered table checkbox columns to match dropdown order (COI → State Lic → BTR)
- Send button disables with spinner on submit to prevent double-clicks
- Default entity view changed to show all departments; "Show Pending Only" is now the filter option
- Fixed CSRF token missing error on company docs upload form
- Fixed `NameError: documents not defined` (import was function-level, not module-level)
