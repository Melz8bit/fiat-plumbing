## Work Done

### Email Documents Feature
- **`app.py`**:
  - Added env vars: `AOL_EMAIL`, `AOL_APP_PASSWORD`, `AFIAT_GMAIL_EMAIL`, `AFIAT_GMAIL_APP_PASSWORD`, `VENTURA_CLIENT_ID = "10"`
  - Updated `project_view` to also load `project_documents`, `doc_contacts` (contacts with emails), `doc_default_from_email`, and `doc_from_emails` for the modal
  - New route `POST /project/<project_id>/documents/send`:
    - Validates at least one To recipient and one document
    - Fetches contacts by ID, resolves selected docs from DB
    - Auto-generates email body if textarea left blank (greeting uses recipient name if only one To)
    - Sends via AOL SMTP (default) or Gmail SMTP (Ventura client_id=10)
    - Attaches files fetched from S3 via `download_file()`
    - Adds project note on success: "Documents emailed to client: [types]"
    - Sets `session["active_tab"] = "documents"`, flashes success message
    - Returns JSON `{success: true/false}`
  - Fixed bug: `user['first_name']` → `user.first_name` (get_user returns Row, not RowMapping)
  - Project address in email body/subject uses street address only (no city/state)

- **`templates/project.html`**:
  - Added `#sendDocModal` with `modal-dialog-scrollable` class
  - From dropdown (AOL default, Gmail for Ventura)
  - Recipients list: per-contact To/CC dropdown (only contacts with email)
  - Documents: custom Bootstrap dropdown (max-height 220px, scrollable) + Attach button + attached list with Remove button
  - Auto-generated placeholder updates dynamically as user changes selections
  - Modal resets on open (clears attached docs, recipient selections, body)
  - Send button: validates, submits via `fetch`, reloads on success, shows inline error on failure

- **`templates/project_documents.html`**:
  - Added "Send Documents" button (disabled when no docs) that triggers `#sendDocModal` in parent page
  - Modal and JS moved out (scripts in AJAX-loaded partials don't execute via innerHTML)
